// A STOREFRONT LANE, IF EVER

Why not here

GitHub Pages' terms do not allow running a store. Both lanes stay showcases; commerce stays on the shop's own portal.

GitHub Pages: no e-commerce
Where it could live

Netlify's free plan allows commercial sites; Cloudflare Pages is the other candidate. Vercel's Hobby plan is non-commercial only. Payments would stay with a provider built for it: a Shopify Buy Button or Storefront API, or Stripe Checkout.
